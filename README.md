# El prompt con el que Claude hizo estos videos en automático

Página regalo del CTA **ESTRATEGIA** (@soydiegoosorio): los prompts de 4 videos hechos con un clon de IA
(Nunca subestimes al de las gafas, Un caballero en Nueva York, Le ayudé a un gigante, Un mundo sin ruido) y la estrategia con la que usamos los
agentes de IA en los negocios.

Página: https://diegodoc1111.github.io/estrategia-ia/

## Fuentes verificadas
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup
- Higgsfield CLI (`npm install -g @higgsfield/cli`, `higgsfield auth login`): mismo paso de la guía
  https://diegodoc1111.github.io/clonarte-con-ia/ y el CLI que usamos para estos videos.
- Costo por segundo (Seedance 2.5, 480p, unos 3 créditos/s): cobros reales de la cuenta al hacer estos videos.
- Los prompts técnicos (`docs/prompts/*.txt`) son los que escribió Claude para cada video, sin datos personales.
- "Nunca subestimes al de las gafas" (24-nov-2026): 8 tomas de Seedance 2.5 con un bloqueo de Blender como video de
  referencia; el archivo técnico usa un emblema genérico ([YOUR EMBLEM]), sin marcas.
